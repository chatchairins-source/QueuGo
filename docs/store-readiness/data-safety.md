# Data Safety — แบบร่างตามซอร์ส Native Android

Google Play นับข้อมูลที่ส่งออกจากอุปกรณ์ รวมถึง SDK และข้อมูลที่ประมวลผลชั่วคราว ให้ประเมิน collection, sharing, purpose, required/optional และ ephemeral แยกตามชนิดข้อมูลและทุกเวอร์ชันที่เผยแพร่ภายใต้ package เดียวกัน [คู่มือ Google Play](https://support.google.com/googleplay/android-developer/answer/10787469)
