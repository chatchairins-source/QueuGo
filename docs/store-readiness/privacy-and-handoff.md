# Privacy Policy, Account Deletion และ PDPA

## สิ่งที่ตรวจได้

- [Privacy Policy สาธารณะ](https://chatchairins-source.github.io/QueuGo/docs/privacy.html) ระบุ QueueTech, ข้อมูลบัญชี ตำแหน่ง ออเดอร์ รูป แชต อุปกรณ์ การโทร คู่สัญญา การเก็บข้อมูล และการลบ ระบุว่าเสียงสนทนาไม่ถูกบันทึก และข้อมูลสถานะการโทร/แจ้งเตือนสายมีอายุ 30 วันตามนโยบาย [ซอร์ส](https://github.com/chatchairins-source/QueuGo/blob/369e4b49b20a0781f6d52be1c54aef5bd473609d/docs/privacy.html#L14-L29)
- [หน้า Account Deletion สาธารณะ](https://chatchairins-source.github.io/QueuGo/docs/account-deletion.html) ให้ยืนยันเจ้าของด้วยเบอร์/อีเมลและรหัสผ่าน พิมพ์ข้อความยืนยัน และส่งคำขอผ่าน shared JS ไปยัง `account-delete` อธิบายธุรกรรมที่อาจเก็บต่อและข้อจำกัดงานค้าง [หน้าเว็บ](https://github.com/chatchairins-source/QueuGo/blob/369e4b49b20a0781f6d52be1c54aef5bd473609d/docs/account-deletion.html#L15-L26) · [ขั้นตอน](https://github.com/chatchairins-source/QueuGo/blob/369e4b49b20a0781f6d52be1c54aef5bd473609d/docs/account-deletion.html#L40-L55) · [JS](https://github.com/chatchairins-source/QueuGo/blob/369e4b49b20a0781f6d52be1c54aef5bd473609d/account-deletion.js#L14-L36)
- พบเมนูลบถาวรใน [Customer](https://github.com/chatchairins-source/QueuGo/blob/f30e54020562cad7c72f1eb0ce454507e2a58342/native-android/customer/src/main/java/com/queuego/customer/QueueGoCustomerApp.kt#L2099), [Merchant](https://github.com/chatchairins-source/QueuGo/blob/f30e54020562cad7c72f1eb0ce454507e2a58342/native-android/merchant/src/main/java/com/queuego/merchant/QueueGoMerchantApp.kt#L2510-L2511) และ [Rider](https://github.com/chatchairins-source/QueuGo/blob/f30e54020562cad7c72f1eb0ce454507e2a58342/native-android/rider/src/main/java/com/queuego/rider/RiderProfileScreen.kt#L321-L331) และพบ shared API ไป endpoint เดียวกัน [Native API](https://github.com/chatchairins-source/QueuGo/blob/f30e54020562cad7c72f1eb0ce454507e2a58342/native-android/shared/src/main/java/com/queuego/shared/QueueGoAccountDeletion.kt#L51-L78)
- SQL ใน repository ครอบคลุมแจ้งเตือน/สถานะการโทร แชต support tokens และข้อมูลบางส่วนของ Rider [cleanup](https://github.com/chatchairins-source/QueuGo/blob/369e4b49b20a0781f6d52be1c54aef5bd473609d/QueueGo-Pilot-Account-Deletion-Privacy.sql#L314-L348) · [profile/session](https://github.com/chatchairins-source/QueuGo/blob/369e4b49b20a0781f6d52be1c54aef5bd473609d/QueueGo-Pilot-Account-Deletion-Privacy.sql#L392-L430) รอบนี้ตรวจหน้าแบบไม่ล็อกอินและตรวจซอร์ส ยังไม่มีหลักฐานทดสอบลบจริงทั้งสามบทบาทหรือยืนยัน deploy ของ endpoint และ cleanup สื่อทุก bucket

## ให้ผู้เชี่ยวชาญกฎหมายไทยตรวจทาน

- ม.22–25 และ ม.27: ตรวจฐานและความจำเป็นแยกตามบัญชี การจัดส่ง ตำแหน่ง Rider POS การโทร การตรวจเอกสาร และการส่งเสริมการขาย รวม notice ณ จุดเก็บและการรับข้อมูลจากผู้อื่น
- ม.26: ตรวจว่าภาพ/เอกสารมีข้อมูลอ่อนไหวหรือมีการประมวลผลเพื่อยืนยันตัวตนแบบชีวมิติหรือไม่ กำหนดการปิดข้อมูลเกินจำเป็นในบัตร เอกสาร และภาพ
- ม.28–29 และ ม.40: ตรวจการโอนออกนอกประเทศและสัญญาผู้ประมวลผลกับ Supabase, Firebase, TURN, CDN/แผนที่ รวมบทบาทของร้านและไรเดอร์ในข้อมูลออเดอร์
- ม.19, 30–36 และ 73: ยืนยันช่องทางถอนความยินยอม เข้าถึง โอน คัดค้าน ลบ จำกัด แก้ไข และร้องเรียน รวมการตรวจตัวตนและข้อยกเว้นข้อมูลบัญชี/ข้อพิพาท
- ม.37, 39 และ 41: ตรวจอายุข้อมูลจริงและ backup, กระบวนการแจ้งเหตุละเมิดและเกณฑ์ 72 ชั่วโมงเมื่อเข้าเงื่อนไข, บันทึกกิจกรรม และเกณฑ์แต่งตั้ง DPO
