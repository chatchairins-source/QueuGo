ขอบเขตพื้นที่บริการประเทศไทย

ใช้ขอบเขต geoBoundaries Thailand ADM0 (THA-ADM0-76911100) จาก OpenStreetMap / Wambacher เป็นชุดข้อมูลแยก ภายใต้ Open Database License (ODbL) 1.0 ข้อมูลต้นฉบับระบุปีพื้นที่ 2017 และสร้างชุดเผยแพร่ในปี 2023 ขอบเขตนี้ใช้ตรวจพื้นที่บริการ ไม่ใช่หลักฐานเขตแดนทางกฎหมายหรือการรับรองว่าทุกจุดมีร้านค้าและไรเดอร์พร้อมให้บริการ
