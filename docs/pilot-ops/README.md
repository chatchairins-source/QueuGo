## ก่อนเปิดกะ

1. อ่านบันทึก Go/No-Go ล่าสุดและเช็กว่าเวลานี้อยู่ในรอบ พื้นที่ และประเภทบริการที่อนุมัติ ตรวจว่าร้าน ไรเดอร์ เวรสนับสนุน และผู้รับช่วงติดต่อกันได้ผ่านช่องทางที่อนุมัติ หากข้อมูลยังขาด ให้ผู้ประสานพื้นที่คงสถานะ No-Go
2. เปิดรายการงานค้าง ตรวจผู้รับผิดชอบรายออเดอร์และยอดที่รอตรวจ ให้เวรเดิมส่งมอบเลขเคส สถานะล่าสุด และเวลานัดอัปเดตในช่องทางจำกัดสิทธิ์
3. เมื่อปิดกะ ตรวจออเดอร์ค้างและบิลที่ผลยังไม่ชัด ระบุผู้รับช่วง ช่วงเวลาที่ติดตามได้ และส่งต่อเคสยอดเงินให้ผู้มีสิทธิ์ตรวจรายการเดิม

ลิงก์บรรทัดของโค้ดระบุ SHA คงที่เพื่อให้ย้อนตรวจได้ สถานะ **ตรวจซอร์สแล้ว** ยืนยันพฤติกรรมที่อ่านได้จากโค้ด ส่วน **PENDING/NOT VERIFIED** ใช้เมื่อยังขาดหลักฐานบนรุ่นและสภาพแวดล้อมที่จะเปิดจริง ช่องทางติดต่อและชื่อเวรใช้ทะเบียนกะที่ทีมอนุมัติและจำกัดสิทธิ์
