# เริ่มใช้งานสำหรับไรเดอร์

## ก่อนเปิดรับงาน

1. เข้าด้วยบัญชีไรเดอร์ที่ผ่านการอนุมัติจากแอดมิน ตรวจว่าเป็นบัญชีของตน เปิดสิทธิ์ตำแหน่งและการแจ้งเตือนตามที่แอปขอ ตรวจจุดปัจจุบันบนแผนที่และดูสถานะการแจ้งเตือนเบื้องหลัง
2. เมื่ออยู่ในพื้นที่และกะที่อนุมัติ เปิดรับงานและรอให้หน้าจอยืนยันว่า **ออนไลน์** หากปุ่มค้างหรือสถานะไม่ยืนยัน ให้แจ้งเวรประสานก่อนรับงาน
3. หากใช้ Android ให้ใช้รุ่นที่ QA และผู้ประสานพื้นที่รับรองสำหรับกะนั้น ผลตรวจตำแหน่ง Push เมื่อสลับแอป การกลับเข้าแอป และการนำทางออฟไลน์ของรุ่นที่จะเปิดยัง **PENDING/NOT VERIFIED**

## ส่งออเดอร์ร้านค้าทั่วไป

| เหตุการณ์จริง | ทำในแอปตามสถานะที่แสดง |
| --- | --- |
| เห็นข้อเสนองาน | ตรวจจุดรับและจุดส่ง กดรับ และตรวจว่างานเข้ารายการงานของตน |
| ไปถึงร้าน | กดแจ้งถึงร้านเมื่อปุ่มแสดง หากร้านยังเตรียมของให้รอสถานะพร้อมรับ |
| ร้านส่งมอบสินค้า | ตรวจรายการและเลขออเดอร์ แล้วทำขั้นตอนยืนยันรับสินค้าตามหน้าจอ |
| รับสินค้าแล้ว | เลือกเริ่มไปส่งลูกค้า ตรวจสถานะกำลังจัดส่ง |
| ถึงลูกค้า | กด **ถึงแล้ว** ตามขั้นตอนจริง ตรวจจุดส่งและส่งมอบ |
| ส่งมอบแล้ว | ส่งรูปหลักฐานตามที่หน้าจอขอ ตรวจว่าระบบแสดง **จัดส่งสำเร็จ** หากอัปโหลดค้าง ให้ตรวจงานเดิมและส่งต่อเคส |

ลำดับนี้อ้างอิง Web สำหรับออเดอร์ร้านค้าทั่วไป งานตลาดหลายร้านมีขั้นตอนยืนยันรับทีละจุด งานรูปแบบอื่นให้ทำตามหน้าจอของบริการที่อนุมัติ หากขั้นตอนติดขัดให้ใช้เมนู **แจ้งปัญหางาน** หรือช่องทางเวรที่ได้รับอนุมัติ

## GPS แผนที่ หรือเครือข่ายผิดปกติ

จอดในจุดปลอดภัยก่อนใช้งานโทรศัพท์ ตรวจสิทธิ์ตำแหน่ง สัญญาณ และจุดรับหรือส่งจากงานเดิม ถ้ายังตรวจเส้นทางไม่ได้ ให้ประสานเวรเพื่อยืนยันทางเลือกและแจ้งลูกค้าผ่านช่องทางออเดอร์ที่อนุมัติ หากอัปเดตงานไม่ได้ ให้แจ้งเลขออเดอร์และขั้นตอนที่ทำจริง คงสถานะตามที่เซิร์ฟเวอร์ยืนยัน หลีกเลี่ยงการกดซ้ำหลายครั้งและงดปิดงานก่อนส่งมอบ หากมีงานค้างให้ประสานก่อนเปลี่ยนสถานะรับงาน

การนำทางออฟไลน์ประเทศไทยและการคำนวณเส้นทางใหม่บนรุ่นนำร่องยัง **PENDING/NOT VERIFIED** งานสร้างกราฟของ [run 43509849584](https://github.com/chatchairins-source/QueuGo/actions/runs/43509849584) ล้มเหลวและขั้นเผยแพร่ APK ที่ตรวจแล้วถูกข้าม ดู [การรับมือเหตุขัดข้อง](incident-runbook.md)
