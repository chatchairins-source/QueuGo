# เริ่มใช้งานสำหรับร้านค้า

## สมัครและเตรียมเปิดร้าน

1. เปิด Merchant Web จากช่องทางที่ผู้ประสานพื้นที่ให้ไว้ กรอกชื่อผู้สมัคร ชื่อร้าน ประเภทร้าน เบอร์โทร และรหัสผ่านตามแบบฟอร์ม ร้านช้อปปิ้งเลือกหมวดย่อยตามที่ระบบขอ ร้านตลาดสดทำตามช่องข้อมูลตลาดและตำแหน่งที่แสดง ส่งใบสมัครและรอแอดมินอนุมัติ
2. เข้าบัญชีร้านที่ได้รับอนุมัติ ตรวจชื่อ ประเภท และหมุดร้านในข้อมูลร้าน ตั้ง **เวลาทำการและวันหยุด** ตรวจสถานะเปิดร้านและความพร้อม Delivery บนหน้าร้าน ให้ผู้ประสานพื้นที่ยืนยันพื้นที่และช่วงเวลาเปิดรับที่อนุมัติ
3. เพิ่มหรือแก้รายการสินค้า ตรวจชื่อ หมวด ราคา รูป สต็อก และช่องทางขายที่ระบบแสดง หากขายทั้งหน้าร้านและจัดส่ง ให้ตรวจราคาของแต่ละช่องทาง เมื่อมีออเดอร์จัดส่ง ให้ยืนยันรายการและกดรับ → เริ่มเตรียม → แจ้งพร้อมรับตามปุ่มที่ขึ้นจริง ส่งมอบตามเลขออเดอร์และตรวจรายการกับไรเดอร์

## ขายหน้าร้านผ่าน Web POS

1. เปิด POS ด้วยบัญชีเจ้าของร้านหรือพนักงานที่มีสิทธิ์ เลือกประเภทบิลตามรายการขาย ถ้าเป็นทานที่ร้านให้เลือกโต๊ะหรือเลือกไม่ระบุโต๊ะตามหน้าจอ ตรวจสินค้า จำนวน และยอดก่อนคิดเงิน
2. สแกนหรือกรอกรหัสในช่อง POS ตอนออนไลน์ ตรวจรายการที่เพิ่มเข้าบิลทุกครั้ง หากรหัสไม่พบหรือแสดงสินค้าคนละรายการ ให้หยุดสแกนรายการนั้นและให้ผู้มีสิทธิ์จัดการรหัสสินค้าเข้าตรวจ การใช้งานสแกนเนอร์ของร้านและสิทธิ์บัญชีบนรุ่นนำร่องยัง **PENDING/NOT VERIFIED**
3. ในหน้า **คิดเงิน** เงินสดให้กรอกยอดรับและตรวจเงินทอน ส่วนโอนเงิน พร้อมเพย์ และบัตรเป็นตัวเลือกบันทึกช่องทางในบิล POS หลังยืนยันว่ารับเงินจริงผ่านช่องทางที่ร้านได้รับอนุมัติ ซอร์สเรียก `pos_take_payment` เพื่อบันทึกและปิดบิล การรับชำระผ่าน QR อัตโนมัติ การเชื่อมเครื่องรูด และการตัดยอดจากผู้ให้บริการยัง **PENDING/NOT VERIFIED** ส่วน QR สั่งอาหารที่โต๊ะเป็นอีกขั้นตอนหนึ่ง ให้รอผลยืนยันขอบเขตก่อนนำมาใช้
4. หากหลังคิดเงินผลไม่ชัด ให้เปิดตรวจบิลเดิมและหลักฐานจากช่องทางรับเงิน หากยังยืนยันไม่ได้ให้หยุดเรียกเก็บซ้ำ ส่งเลขบิล เวลา ยอด และสถานะที่เห็นให้เวรสนับสนุน

## หากอินเทอร์เน็ตขาด

ถ้ามีเมนูร่างตะกร้าในรุ่นที่อนุมัติ ให้เก็บร่างบนบัญชีและอุปกรณ์เดิม ร่างยังไม่ใช่บิลชำระแล้วและไม่ส่งเข้าครัว เมื่อออนไลน์อีกครั้ง ตรวจราคา สินค้า และโต๊ะก่อนส่งร่าง รอเลขบิลจากระบบก่อนทำขั้นตอนถัดไป หากมีรายการเดิมรอยืนยัน ให้ตรวจรายการเดิมก่อนสร้างบิลใหม่ หากเข้าใช้ไม่ได้หรือเกิดยอดผิด ให้ใช้ [ขั้นตอนดูแลลูกค้า](customer-support.md)
