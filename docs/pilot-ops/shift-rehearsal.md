# ซ้อมเปิดกะและรับเหตุพื้นที่นำร่อง

ใช้คู่กับ [คู่มือเปิดกะ](README.md), [ขั้นตอนดูแลลูกค้า](customer-support.md) และ [Incident Runbook](incident-runbook.md) ผู้ประสานพื้นที่เตรียมกรณีสมมติให้เวรตอบตามบทบาท ซ้อมบนโต๊ะด้วยเลขออเดอร์และยอดสมมติ การซ้อมนี้ให้หลักฐานการประสานงาน ส่วนผลระบบและการเงินอ้างอิงหลักฐานของ QA ใน [รายการ Go/No-Go](pilot-go-no-go.md)

## ก่อนซ้อม

- ระบุขอบเขตจุดรับ–ส่ง เวลา บริการ วิธีชำระ และรุ่นที่เสนอเปิด หากยังไม่มีมติให้บันทึกว่า “รอยืนยัน”
- ระบุเวรหลักและสำรองของร้านค้า ไรเดอร์ ดูแลลูกค้า การเงิน และหัวหน้าเหตุการณ์ ระบุผู้มีสิทธิ์พักหรือเปิดรับงานใหม่และวิธีติดต่อในทะเบียนเวรจำกัดสิทธิ์
- ให้ผู้คุมการซ้อมแจ้งเวลาเริ่ม (ICT) และแจ้งทุกคนว่าข้อความที่ส่งเป็นการซ้อม ใช้ช่องทางภายในที่ได้รับอนุมัติและบันทึกผลว่าติดต่อผู้รับช่วงได้จริงหรือไม่

## สถานการณ์และเกณฑ์ผ่านการซ้อม

| สถานการณ์ที่แจ้งแก่เวร | สิ่งที่ผู้คุมการซ้อมต้องเห็น |
| --- | --- |
| ลูกค้ารายงานว่าถูกเรียกเก็บเงิน แต่หาออเดอร์ไม่พบ | เปิดเลขเคส ตรวจรายการเดิม ส่งผู้มีสิทธิ์กระทบยอด นัดอัปเดต และหยุดขอให้สั่งหรือชำระซ้ำจนยืนยันผล |
| ร้านพร้อมส่ง แต่ไรเดอร์ไม่มีสัญญาณและหาจุดส่งไม่พบ | ให้ไรเดอร์จอดในจุดปลอดภัย เวรระบุสถานะที่ยืนยันล่าสุด ผู้ประสานจุดส่ง และผู้รับช่วงออเดอร์ ถ้าปิดงานไม่ได้ให้รวมไว้ในงานค้าง |
| Checkout ล้มเหลวหลายรายการและสถานะร้านกับลูกค้าไม่ตรง | ระบุผู้ตัดสินใจพักรับงาน บริการที่ได้รับผล ผู้ดูแลออเดอร์เดิมแต่ละรายการ และข้อความแจ้งผู้ใช้ ระบุวิธียืนยันการพักและหลักฐานที่ต้องเห็นก่อนเปิดใหม่ |
| ไรเดอร์รายงานอุบัติเหตุระหว่างส่ง | ให้ความปลอดภัยและการติดต่อหน่วยฉุกเฉินมาก่อน ผู้ประสานรับช่วงออเดอร์และจำกัดสิทธิ์เข้าถึงรายละเอียดเหตุ |
| เวรหลักติดต่อไม่ได้ระหว่างมีเคสค้าง | เวรสำรองยืนยันรับช่วงด้วยเลขเคส สถานะล่าสุด ผู้รับผิดชอบ และเวลานัดอัปเดต |

## บันทึกผลและส่งต่อ

คัดลอกแบบบันทึกไปเก็บในทะเบียนกะที่จำกัดสิทธิ์ ใช้ผล “ผ่าน”, “ต้องซ้อมใหม่” หรือ “ยังไม่ได้ซ้อม” ตามสิ่งที่เกิดจริง

| รายการ | กรอกเมื่อซ้อม |
| --- | --- |
| วันและเวลา (ICT) / พื้นที่ / ผู้คุมการซ้อม | |
| เวรหลักและสำรอง / ผลทดลองติดต่อ | |
| ขอบเขตบริการและรุ่นที่เสนอเปิด / ผู้มีสิทธิ์พักหรือเปิดใหม่ | |
| สถานการณ์ / สถานะที่ยืนยัน / การตัดสินใจ / เวลานัดอัปเดต | |
| ผลรายสถานการณ์ / ลิงก์หลักฐานจำกัดสิทธิ์ | |
| ประเด็นที่ต้องแก้ / ผู้รับผิดชอบ / นัดซ้อมซ้ำ | |

แนบผลในช่อง “เวรสนับสนุนและแผนหยุด/เปิดใหม่” ของ [บันทึก Go/No-Go](pilot-go-no-go.md) เมื่อมีผลซ้อมจริง หากยังไม่มีเวร ผู้รับช่วง หรือผู้มีอำนาจสั่งพัก ให้คงผลรายการตรวจรับนั้นเป็น PENDING/NOT VERIFIED
