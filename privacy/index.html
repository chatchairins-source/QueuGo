นโยบายความเป็นส่วนตัว

QueueGo ใช้ข้อมูลเท่าที่จำเป็นเพื่อให้บริการสั่งอาหาร/สินค้า ตลาดสด ฝากซัก ร้านค้า POS การจัดส่ง และการช่วยเหลือผู้ใช้ โดยยึดหลักลดการเก็บข้อมูลและจำกัดสิทธิ์ตามบทบาทของผู้ใช้

ข้อมูลที่เราเก็บ

  • ข้อมูลบัญชี เช่น ชื่อ เบอร์โทร อีเมล และสถานะบัญชี
  • ตำแหน่งและที่อยู่เมื่อจำเป็นต่อการเลือกร้าน คำนวณบริการ รับสินค้า นำทาง และส่งสินค้า
  • ข้อมูลออเดอร์ ยอดเงินสด สินค้า ร้านค้า Rider สถานะงาน และเหตุการณ์ที่จำเป็นต่อการให้บริการ
  • รูปหรือไฟล์ที่ผู้ใช้ตั้งใจอัปโหลด เช่น รูปร้าน เอกสารประกอบการสมัคร หรือหลักฐานรับ/ส่งงาน
  • ข้อมูลอุปกรณ์สำหรับการแจ้งเตือนและข้อมูลความปลอดภัยที่จำเป็นต่อการป้องกันการใช้งานผิดปกติ

เราใช้ข้อมูลอย่างไร

เพื่อให้บริการตามคำสั่งของผู้ใช้ จับคู่ร้าน/งานจัดส่ง แสดงสถานะออเดอร์ สนับสนุนลูกค้า ป้องกันการทุจริต รักษาความปลอดภัย ตรวจสอบข้อพิพาท และปฏิบัติตามหน้าที่ทางกฎหมายหรือบัญชีที่เกี่ยวข้อง

ตำแหน่งที่ตั้ง

QueueGo ขอใช้ตำแหน่งเมื่อฟังก์ชันนั้นจำเป็น เช่น การเลือกจุดส่ง การหาแหล่งบริการใกล้เคียง หรือ Rider เปิดรับงาน/นำทาง ผู้ใช้สามารถควบคุมสิทธิ์ตำแหน่งจากระบบปฏิบัติการได้

การเก็บรักษาและการลบบัญชี

ผู้ใช้ลบบัญชีได้จากในแอป และจากหน้าเว็บลบบัญชีของ QueueGo

เมื่อการลบบัญชีสำเร็จ QueueGo จะลบ Supabase Authentication, session, การแจ้งเตือน ความชอบ/รายการโปรด การสนทนาหรือคำขอช่วยเหลือของบัญชี ไฟล์ที่บัญชีเป็นเจ้าของ และข้อมูลระบุตัวบุคคลในโปรไฟล์/ตำแหน่งที่ไม่จำเป็นต่อไป

ประวัติธุรกรรมที่เสร็จสิ้นแล้ว เช่น เลขออเดอร์ รายการสินค้า ยอดเงิน ค่าบริการ และเหตุการณ์ทางบัญชี อาจถูกเก็บไว้เท่าที่จำเป็นต่อการบัญชี ความปลอดภัย การป้องกันทุจริต การระงับข้อพิพาท หรือระยะเวลาที่กฎหมายที่เกี่ยวข้องกำหนด โดย QueueGo จะตัดข้อมูลส่วนบุคคลที่ไม่จำเป็นและเปลี่ยนบัญชีเป็นข้อมูลอ้างอิงที่ไม่แสดงตัวตนต่อผู้ใช้งานทั่วไป

ความปลอดภัย

QueueGo ใช้การยืนยันตัวตน, Row Level Security (RLS), การแยกสิทธิ์ Customer / Merchant / Rider / Admin และให้การดำเนินการที่มีสิทธิ์สูง เช่น การลบบัญชี ทำงานเฉพาะฝั่งเซิร์ฟเวอร์ ไม่ฝังคีย์ลับไว้ในแอปหรือหน้าเว็บสาธารณะ

ติดต่อและสิทธิ์ของผู้ใช้

ผู้ใช้สามารถแจ้งปัญหาหรือสอบถามเกี่ยวกับข้อมูลผ่านเมนู “ติดต่อฝ่ายช่วยเหลือ” ใน QueueGo ได้ หากต้องการลบบัญชีโดยตรง ให้ใช้หน้าลบบัญชีด้านล่าง
